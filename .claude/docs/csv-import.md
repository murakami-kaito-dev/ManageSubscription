# CSV エクスポート / インポート

## エクスポート（`services/csv/csv_export_service.dart`）
全サブスクを CSV 化し OS 共有シートへ。プレミアム限定。UTF-8＋BOM（Excel対応）。
見出し行（13列）:
`サービス名, 金額, 通貨, 周期, 初回支払日, 次回支払日, カテゴリー, 支払い方法, 月額換算, 利用回数/月, 1回あたり単価, 状態, メモ`

## インポート（`services/csv/csv_import_service.dart`）
方針: **解析→検証→プレビュー→ユーザー確定で初めて追加**。追加のみ（新規UUID）で既存データは上書き/削除しない。不正な行はスキップ。

### フロー
1. `pickCsvText()`（file_picker、UTF-8 で寛容デコード）
2. `parse(content, {categoryNameToId, methodNameToId, startSortOrder})` → `CsvImportResult`
3. `CsvImportPreviewScreen` で確認 → `subscriptionsProvider.saveAll(valid)`

### 100件上限との整合（ユーザーが選ぶ方式）
現在件数と合わせて **100件（`PremiumLimits.hardMaxSubscriptions`）** を超えないよう制御する。
`remaining = 100 - 現在件数` を残り枠とし、プレビュー画面（`CsvImportPreviewScreen`）で分岐:
- **全部が収まる**（`validCount <= remaining`）: 従来どおり全件をそのまま取り込む（チェックボックスなし）。
- **収まらない**（`validCount > remaining`）: 各行に**チェックボックス**を出し、**ユーザーが取り込む行を選ぶ**。
  勝手に先頭 N 件へ切り詰める旧仕様は廃止（どれが選ばれたか不透明だったため）。
  - ヘッダーは `_SelectionBar`：見出し「⚠️取り込む項目を選択」＋「あと◯件まで選べます」＋ **全選択 / 全解除**。
  - **全選択は残り枠に関係なく“全件”を選ぶ**（例 `120 / 97`）。上限超過は許容し、カウンタは赤字。
  - **全解除**は選択をすべて外す（0 件）。個別タップは自由にトグル（上限で止めない）。
  - 取り込みボタン：`1 <= 選択数 <= remaining` のときだけ活性。0件＝「取り込む項目を選択してください」、
    超過中＝「選択を◯件以下にしてください」で**非活性**。よって取り込みは常に残り枠以内。
- **残り枠が0**（`remaining <= 0`）: 取り込み不可。ボタンは「これ以上追加できません（上限100件）」で無効。

### 必須列
`サービス名 / 金額 / 通貨 / 周期 / 初回支払日`。欠けると**ファイル全体を拒否**（`fatal`）。

### 列ごとの許可/禁止
「禁止」＝その値だと**その行がスキップ**されるもの（それ以外は「なし」）。
| 列 | 必須 | 許可 | 禁止（→行スキップ） |
|---|---|---|---|
| サービス名 | 必須 | 任意文字列 | 空欄 |
| 金額 | 必須 | 0〜100,000,000、カンマ/¥可 | 空・文字・負・1億超・非有限 |
| 通貨 | 必須 | JPY/USD/EUR/GBP（大小文字可） | 空・左記以外 |
| 周期 | 必須 | 月/年/週、またはカスタム 3ヶ月・2週・5日 | 空・左記以外の語（カスタム回数は1〜999にクランプ＝スキップしない） |
| 初回支払日 | 必須 | yyyy/MM/dd（-・.区切り可）、2000〜2100 | 空・存在しない日付・範囲外年・形式不正 |
| カテゴリー/支払い方法 | 任意 | 既存名 | なし（不一致は「未設定」。スキップしない） |
| 利用回数/月 | 任意 | 数値 | なし（不正・空は0。スキップしない） |
| 状態 | 任意 | 「停止中」＝停止、他＝利用中 | なし |
| メモ | 任意 | 任意文字列 | なし |
| 次回支払日/月額換算/1回あたり単価 | 無視 | エクスポート専用 | なし（読み込まない） |

### 結果とエラー表示
`CsvImportResult { valid: List<Subscription>, errors: List<CsvRowError>, fatal }`。
`CsvRowError { line, name?, messages[] }` — **1行=1グループ**。パーサは1行の全項目を検証し、全エラーを収集（最初で止めない）。
プレビューは項目ごとに枠囲いし、見出し `heading` を「名前（◯行目）」（名前不明なら「（◯行目）」）で表示、中に該当エラーを列挙。

### 書式ヘルプ（`features/csv/csv_import_help_screen.dart`）
設定「CSVの書式・サンプル」/ 取り込み失敗時の「書式を見る」から到達。各列の説明＋
「テンプレート（サンプル）を共有」で正しい形式の CSV を配布。
