# CSV エクスポート / インポート

## エクスポート（`services/csv/csv_export_service.dart`）
全サブスクを CSV 化し OS 共有シートへ。プレミアム限定。UTF-8＋BOM（Excel対応）。
見出し行（13列）:
`サービス名, 金額, 通貨, 周期, 初回支払日, 次回支払日, カテゴリー, 支払い方法, 月額換算, 利用回数/月, 1回あたり単価, 状態, メモ`

## インポート（`services/csv/csv_import_service.dart`）
方針: **解析→検証→プレビュー→ユーザー確定で初めて追加**。追加のみ（新規UUID）で既存データは上書き/削除しない。不正な行はスキップ。

### フロー
1. `pickCsvText()`（file_picker、UTF-8 で寛容デコード）
2. `parse(content, {categoryNameToId, methodNameToId, startSortOrder})` → `CsvImportResult`
3. `CsvImportPreviewScreen` で確認 → `subscriptionsProvider.saveAll(valid)`

### 必須列
`サービス名 / 金額 / 通貨 / 周期 / 初回支払日`。欠けると**ファイル全体を拒否**（`fatal`）。

### 列ごとの許可/禁止
| 列 | 必須 | 許可 | 禁止・注意 |
|---|---|---|---|
| サービス名 | 必須 | 任意文字列 | 空欄 |
| 金額 | 必須 | 0〜100,000,000、カンマ/¥可 | 空・文字・負・1億超・非有限 |
| 通貨 | 必須 | JPY/USD/EUR/GBP（大小文字可） | 左記以外 |
| 周期 | 必須 | 月/年/週、またはカスタム 3ヶ月・2週・5日 | 左記以外。カスタム回数は1〜999にクランプ |
| 初回支払日 | 必須 | yyyy/MM/dd（-・.区切り可）、2000〜2100 | 存在しない日付・範囲外年 |
| カテゴリー/支払い方法 | 任意 | 既存名 | 不一致は「未設定」 |
| 利用回数/月 | 任意 | 数値 | 不正・空は0 |
| 状態 | 任意 | 「停止中」＝停止、他＝利用中 | — |
| メモ | 任意 | 任意文字列 | — |
| 次回支払日/月額換算/1回あたり単価 | 無視 | エクスポート専用 | 読み込まない |

### 結果とエラー表示
`CsvImportResult { valid: List<Subscription>, errors: List<CsvRowError>, fatal }`。
`CsvRowError { line, name?, messages[] }` — **1行=1グループ**。パーサは1行の全項目を検証し、全エラーを収集（最初で止めない）。
プレビューは項目ごとに枠囲いし、見出し `heading` を「名前（◯行目）」（名前不明なら「（◯行目）」）で表示、中に該当エラーを列挙。

### 書式ヘルプ（`csv_import_help_screen.dart`）
設定「CSVの書式・サンプル」/ 取り込み失敗時の「書式を見る」から到達。各列の説明＋
「テンプレート（サンプル）を共有」で正しい形式の CSV を配布。
