1. サービス内容

本アプリは、利用者が契約するサブスクリプション（定額サービス）の支払い予定・金額・履歴を記録・可視化するためのツールを提供します。表示・計算される金額はあくまで利用者の入力に基づく目安であり、実際の請求額を保証するものではありません。

2. 無料体験について

本アプリは、初回起動時から一定期間（14日間）、すべての機能を無料でご利用いただける体験期間を提供します。体験期間の終了後は、無料プランの範囲でのご利用、または有料プランのご購入を選択できます。体験期間はアプリ内で管理され、Apple の課金を伴いません。

3. 有料プラン（アプリ内課金）

  • 買い切りプラン：一度のお支払いで、対象機能を継続してご利用いただけます（非消耗型のアプリ内課金）。
  • 月額／年額プラン：自動更新されるサブスクリプションです。

4. 自動更新サブスクリプションの条件

  • お支払いは、購入確定時に Apple ID アカウントに請求されます。
  • サブスクリプションは、現在の期間の終了24時間前までに解約されない場合、自動的に更新され、更新分の料金が請求されます。
  • 解約・自動更新の停止は、購入後に端末の「設定」→ Apple ID →「サブスクリプション」からいつでも行えます。
  • 価格は App Store の表示に従い、地域により異なる場合があります。

5. 購入の復元
